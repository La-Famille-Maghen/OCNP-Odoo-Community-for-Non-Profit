# Code de conduite — OCNP

OCNP est un projet de La Famille Maghen, association signataire de la Charte de la Diversité. Toute personne qui participe au projet — contributeurs, utilisateurs, associations pilotes — s'engage à respecter ce code de conduite.

## Nos engagements

Nous nous engageons à faire de la participation à ce projet une expérience respectueuse pour toutes et tous, quels que soient l'âge, le niveau d'expérience, l'origine, le genre, l'identité, l'orientation, le handicap, la religion ou toute autre caractéristique personnelle.

## Comportements attendus

- Faire preuve de respect et de bienveillance dans les échanges.
- Accepter les critiques constructives et les formuler avec soin.
- Se concentrer sur ce qui est utile au projet et aux associations utilisatrices.
- Respecter les règles de confidentialité : ne pas publier de données personnelles, de secrets ou d'informations internes.
- Utiliser uniquement des données fictives dans les issues, tests et pull requests.

## Comportements inacceptables

- Toute forme de harcèlement, discrimination ou propos offensant.
- La publication de données personnelles réelles sans consentement.
- La publication de secrets, identifiants ou informations confidentielles.
- Les comportements qui nuisent à la confiance ou à la sécurité du projet.

## Signalement

Tout comportement contraire à ce code peut être signalé à [contact@maghen.eu](mailto:contact@maghen.eu). Les signalements sont traités avec discrétion.

## Portée

Ce code s'applique dans tous les espaces du projet : dépôt GitHub, issues, pull requests, discussions et tout autre canal de communication lié à OCNP.
