# OCNP-Odoo-Community-for-Non-Profit
ERP complet de gestion associative gratuite en self-host, basée sur Odoo Community sans modification du cœur. OCNP (Odoo Community For Non Profit) structure les besoins des associations principalement à l'aide des modules Core et OCA, afin de garantir un écosystème modulaire, pérenne et conforme à la licence originale open source.
