# Politique de sécurité — OCNP

> [!IMPORTANT]
> **Le projet est en phase de préparation.** Cette politique sera complétée avant la première diffusion stable. Les principes ci-dessous s'appliquent dès maintenant au dépôt public.

## Versions prises en charge

Aucune version stable n'est encore publiée. La première version est en test interne au sein de La Famille Maghen.

## Signaler une vulnérabilité

**Ne publiez pas les détails d'une vulnérabilité dans une issue publique.**

Envoyez un email à [contact@maghen.eu](mailto:contact@maghen.eu) avec :

- l'objet : `[SÉCURITÉ] OCNP — <description courte>`
- une description du problème et des conditions de reproduction
- l'impact potentiel estimé
- si possible, une suggestion de correction

Nous accuserons réception dans les meilleurs délais et vous tiendrons informé du traitement.

## Règles pour ce dépôt

- Ne jamais publier de mot de passe, jeton, clé privée, clé API ou identifiant sensible.
- Ne jamais publier de données personnelles réelles dans les issues, commits, pull requests ou fichiers de démonstration.
- Utiliser uniquement des données synthétiques dans les tests et les environnements de démonstration.
- Signaler toute exposition accidentelle de secret ou de donnée personnelle immédiatement à [contact@maghen.eu](mailto:contact@maghen.eu).

## Responsabilité des installations

OCNP est conçu pour être auto-hébergé. La sécurité d'une installation dépend aussi de la configuration, de l'hébergeur, des mises à jour et des pratiques d'administration de l'association utilisatrice. Consultez le [README](./README.md) et la [présentation complète](./docs/OCNP_presentation_publique_complete.md) pour les principes de sécurité visés.
